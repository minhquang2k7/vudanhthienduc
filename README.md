# Portfolio - Vũ Danh Thiên Đức

## Cấu trúc files - ĐẶT TẤT CẢ VÀO CÙNG 1 THƯ MỤC:

```
/
├── .nojekyll          ← BẮT BUỘC - ngăn Jekyll xử lý file
├── index.html         ← (đổi tên portfolio_fixed.html thành index.html)
├── pdf_bt1.html       ← Bài tập 1 PDF viewer
├── pdf_bt2.html       ← Bài tập 2 PDF viewer
├── pdf_bt3.html       ← Bài tập 3 PDF viewer
├── pdf_bt4.html       ← Bài tập 4 PDF viewer
├── pdf_bt5.html       ← Bài tập 5 PDF viewer
└── pdf_bt6.html       ← Bài tập 6 PDF viewer
```

## Lưu ý quan trọng:
- File `.nojekyll` phải có trong thư mục gốc (root) của repo
- Đổi tên `portfolio_fixed.html` → `index.html` 
- Tất cả file `pdf_bt*.html` phải cùng thư mục với `index.html`
- GitHub Pages → Settings → Pages → Source: `main` branch, `/ (root)`
